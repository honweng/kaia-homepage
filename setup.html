🛠️ 4-Step Quickstart Blueprint
1

Edge Compute

Flash Debian 13 / Pi OS. Enable systemd linger with loginctl enable-linger $USER for boot persistence.

2

Install OpenClaw

Install globally: npm install -g openclaw and run onboarding wizard.

3

Connect Models & Telegram

Get an API key from Google AI Studio and a bot token from @BotFather.

4

Cloudflare Ingress

Install cloudflared to route custom domain traffic to local port 18789 securely.
