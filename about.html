🛠️ Quickstart Blueprint

1

Set Up Edge Compute

Flash Debian 13 or Raspberry Pi OS (64-bit). Enable systemd lingering with loginctl enable-linger $USER so services auto-start on boot.

2

Install OpenClaw

Install the runtime globally using npm install -g openclaw and run the guided onboarding wizard to configure your workspace.

3

Attach Model & Messaging

Obtain an API key from Google AI Studio, create a Telegram bot via @BotFather, and connect the credentials in your config.

4

Establish Zero Trust Ingress

Run cloudflared to route your custom domain directly to your local OpenClaw gateway without exposing public IP addresses.
